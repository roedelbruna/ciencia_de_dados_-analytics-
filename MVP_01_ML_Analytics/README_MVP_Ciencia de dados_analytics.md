# Ciencia_de_dados_-analytics-
# Previsão de Vendas de Combustíveis em Mato Grosso

## Objetivo

Este projeto foi desenvolvido como MVP da pós-graduação em Machine Learning & Analytics da PUC-Rio.
O objetivo é prever o volume de vendas de Gasolina C e Etanol Hidratado no estado de Mato Grosso (MT), utilizando dados públicos da Agência Nacional do Petróleo (ANP).

## Base de Dados
Dados públicos obtidos da ANP:
- Liquidos_Vendas_Atual
- Liquidos_Entregas_Distribuidor_Atual

Fonte:
[https://www.gov.br/anp](https://www.gov.br/anp/pt-br/centrais-de-conteudo/paineis-dinamicos-da-anp/paineis-dinamicos-do-abastecimento/painel-dinamico-do-mercado-brasileiro-de-combustiveis-liquidos)

## Tecnologias Utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn
- Google Colab

## Metodologia
O projeto seguiu as seguintes etapas:

1. Coleta dos dados públicos da ANP
2. Análise exploratória dos dados (EDA)
3. Preparação e tratamento dos dados
4. Construção da série temporal mensal
5. Separação entre treino e teste
6. Desenvolvimento de modelo Baseline
7. Treinamento de Regressão Linear
8. Treinamento de Random Forest
9. Otimização com GridSearchCV
10. Comparação dos resultados

## Resultados
Foram avaliados os modelos Baseline, Regressão Linear e Random Forest utilizando métricas de erro para comparação de desempenho.
